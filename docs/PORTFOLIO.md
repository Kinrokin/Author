# What this project demonstrates

Sovereign Author is a compact public reference implementation extracted from a larger private long-form creative
workflow. The portfolio version focuses on the engineering patterns that generalize beyond fiction:

- multi-provider orchestration without provider lock-in
- deterministic provenance around nondeterministic generators
- human-in-the-loop authority boundaries
- source-version binding and stale-work rejection
- stateful long-horizon workflows
- canon/schema change quarantine
- privacy-preserving public demos
- recovery-friendly, auditable artifacts

The production system that inspired it is deliberately not published here. This repository contains no private
manuscript, real author profile, or production provider transcripts.
