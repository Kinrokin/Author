# Security and privacy

This public repository is intentionally **content-agnostic**. Do not commit unpublished manuscripts,
provider transcripts, API keys, personal author data, or production Writing Room state.

## Reporting
Open a GitHub issue for non-sensitive defects. For a suspected secret or private-content leak, do not
paste the material into a public issue; remove access to the affected artifact and contact the maintainer
through a private channel.

## Trust boundary
Generative model output is untrusted input. The controller parses it into a candidate object but cannot
promote it without a separate human decision. New canon proposals are quarantined from promotion.
